## About

This is the personal portfolio of Ivan Ahonkhai, a junior developer learning web development, Python and creative coding. It collects the projects he has built, with links to live versions and source code.

## Features

- Project gallery covering AI tools, games, and education apps
- Light and dark themes that follow your system setting and remember your choice
- Responsive layout from small phones to wide desktops
- Keyboard-friendly navigation and reduced-motion support

## How to use it

Open the [live site](https://ivanahonkhai.github.io/), scroll to **Projects**, and choose **Live site** to try a project or **Source** to read its code.

## Tech stack

Plain HTML, CSS and JavaScript, hosted on GitHub Pages and deployed with GitHub Actions.

## Project structure

```
index.html      Home page
404.html        Not-found page
assets/         Stylesheet and scripts
docs/           Deployment and customization notes

```
